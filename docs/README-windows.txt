=====================================================
  DIRECTOR 3D — как запустить
=====================================================

1. Распакуйте эту папку ЦЕЛИКОМ куда угодно
   (например, на Рабочий стол).

2. Откройте папку и запустите Director3D.exe
   двойным щелчком.

Всё. Устанавливать ничего не нужно.


-----------------------------------------------------
  ВАЖНО: распаковывать нужно всю папку
-----------------------------------------------------

Не запускайте программу прямо из архива и не вынимайте
из папки один только Director3D.exe.

Рядом с программой лежит папка assets — в ней шрифты и
перевод интерфейса. Без неё программа не запустится или
запустится без букв.


-----------------------------------------------------
  ЕСЛИ WINDOWS РУГАЕТСЯ ПРИ ЗАПУСКЕ
-----------------------------------------------------

Windows может показать синее окно:
   "Система Windows защитила ваш компьютер"

Это не вирус и не поломка. Так Windows встречает любую
программу без платной подписи разработчика.

Что делать:
   1. Нажмите "Подробнее"
   2. Нажмите "Выполнить в любом случае"

Достаточно сделать один раз.


-----------------------------------------------------
  ЕСЛИ ПРОГРАММА НЕ ЗАПУСКАЕТСЯ
-----------------------------------------------------

Рядом с Director3D.exe появится файл director3d.log —
в нём записано, что произошло. Пришлите его, и по нему
будет видно причину.

Самая частая причина — старая видеокарта или очень
старые драйверы. Программе нужен OpenGL 3.3; ему больше
десяти лет, но на совсем древних встроенных видеокартах
его может не быть. Обновление драйверов видеокарты
обычно решает вопрос.


-----------------------------------------------------
  ЯЗЫК ИНТЕРФЕЙСА
-----------------------------------------------------

Меню "Окно" -> "Язык / Language" -> Русский или English.
Выбор запоминается.


-----------------------------------------------------
  ЭКСПОРТ ВИДЕО В MP4 (необязательно)
-----------------------------------------------------

Сама программа, анимация и экспорт картинками (PNG)
работают сразу и ничего не требуют.

MP4-ролик собирает отдельная бесплатная программа
ffmpeg. Если её нет, Director 3D сохранит секвенцию
картинок — из них ролик можно собрать позже.

Чтобы включить MP4:
   1. Скачайте ffmpeg с https://ffmpeg.org/download.html
      (сборка для Windows)
   2. Распакуйте
   3. Положите ffmpeg.exe РЯДОМ с Director3D.exe

Больше ничего настраивать не нужно.
